`astronaut.png` is a NASA photograph of astronaut Eileen Collins, distributed by scikit-image. The scikit-image documentation identifies it as public domain, with no known copyright restrictions.

- Source bytes: https://raw.githubusercontent.com/scikit-image/scikit-image/v0.22.0/skimage/data/astronaut.png
- Attribution and rights statement: https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut
- SHA-256: `88431cd9653ccd539741b555fb0a46b61558b301d4110412b5bc28b5e3ea6cb5`
- Dimensions: 512 by 512 pixels. The source bytes are unchanged.

The simulator resizes this recorded image and applies synthetic effects. No simulator scenario supplies a live subject or a physical printed-photo or screen-replay test. Native controller checks also use this image to check that a passive model score cannot bypass required active evidence. The model's score on one photograph is not an accuracy measurement.

The five inherited JPEG fixtures were removed because their individual provenance and redistribution terms were undocumented.
